## Gotchas
- **`companies.csv` has a UTF-8 BOM.** Always open with `encoding="utf-8-sig"` in Python,
  never `"utf-8"` — otherwise the `id` column header silently breaks (`KeyError: 'id'`).
- **`github-actions[bot]` pushes to `main` every 6h** (Sheet sync). Always
  `git pull --rebase origin main` before pushing. If local changes are in the way,
  `git stash --include-untracked` first, rebase, push, then `git stash pop`.
- **Workday is network-blocked from the VPS** — don't retry Playwright or the CXS API
  against Workday URLs from this VPS, it will not work. See SPEC.md Known Issues.
- **`scraper/notifier.py` uses `curl` via `subprocess`, not `urllib`/`requests`.**
  Direct Python HTTP calls to `api.resend.com` failed silently from the VPS for
  reasons never fully root-caused. If touching this file, keep the curl approach
  or retest thoroughly from the VPS before changing it.
- Resend sender: `alerts@automations-online.uk` (domain verified via Cloudflare DNS).
  Recipient: `grishkoevsey74@gmail.com`. Both set as env vars in `/opt/eng-tracker/.env` on the VPS.

## Conventions
- No build step — `index.html` / `styles.css` / `app.js` are hand-written, no bundler.
- `data/deadlines.js` and `data/deadlines.json` are generated by
  `scripts/sheet_to_js.py` — never hand-edit them.
- Discipline data still lives in the dataset (used for `sectorFor()` grouping and
  CSV export in `app.js`) even though there's no discipline column/filter in the UI
  anymore — sector grouping replaced it.
- Design palette: navy/indigo/cornflower/powder (CSS vars `--navy`, `--indigo`,
  `--blue`, `--powder` in `styles.css`). Amber is the single warm accent, reserved
  for "Rolling" deadline badges — don't introduce other warm colors without reason.
